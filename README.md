# onclimb-cabin

プライベート・勉強用のスキルとデータを置くリポジトリ（私物 Mac 専用）。

IT エンジニアとしての業務用ツール・スキルは [onclimb-industries](https://github.com/onc-limb/onclimb-industries) が正本で、
本リポジトリはその外側 — 個人の金融資産・フリーランスの事業事務・学習/練習・人間関係の記録 — を扱う。
名前の由来: 業務の「industries」に対する、私生活の拠点（cabin）。

## 構成

| ディレクトリ | 内容 |
|---|---|
| `.claude/skills/` | プライベート・勉強用スキル（分類は [skills/README.md](.claude/skills/README.md)） |
| `personas/` | スキル分類ごとの共通ルール |
| `ideas/` | スキルの構想メモ |
| `study/` | AI にコードを書かせない学習用ディレクトリ（git 管理外） |
| `*-data/` ほか | 各スキルのデータ置き場（すべて git 管理外。一部は Google Drive への symlink） |

運用ルールの詳細は [CLAUDE.md](CLAUDE.md) を参照。
